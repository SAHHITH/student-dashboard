## ✨ About the Project

**StudentHub** is a beginner-friendly React.js project designed to provide students with a simple dashboard to view their academic information and learning progress.

The dashboard displays course information, attendance statistics, course progress, and completed assignments in one place.

This project was developed as part of my React.js and Full Stack Development learning journey.

---

## 🚀 Features

- 📊 **Dashboard Statistics** – Displays total courses, completed courses, and attendance.
- 📚 **My Courses** – Displays available courses with their progress.
- 🔍 **Course Search** – Search and filter courses dynamically.
- 📈 **Progress Tracking** – Visual progress bars for each course.
- ✅ **Assignment Counter** – Increase the completed assignment count.
- 🔄 **Reset Option** – Reset the assignment counter.
- 🧩 **Reusable Components** – Uses a reusable `StatCard` component.
- ⚡ **React Hooks** – Uses `useState` to manage application state.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone <your-github-repository-url>
```

**2. Navigate to the project folder**

```bash
cd student-dashboard
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:5173
```
